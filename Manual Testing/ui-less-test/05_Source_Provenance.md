# Source provenance

## Official reference PDFs

The official documents are retained unmodified for local backend evaluation.
They remain publications of their respective publishers. Do not edit their
content, add P.A.T.C.H. approval marks, or represent them as site-specific
procedures.

- Publisher: U.S. Department of Energy

  Second Edition*

  `https://www.energy.gov/sites/prod/files/2014/05/f16/pump.pdf`

- Safety boundary: it is general guidance, not the synthetic asset’s approved

Recalculate final byte size and lowercase SHA-256 after any deliberate download:

```powershell
Get-ChildItem -LiteralPath 'Manual Testing\ui-less-test\pdfs\official' -File |
  ForEach-Object {
    [pscustomobject]@{
      File = $_.Name
      Bytes = $_.Length
      SHA256 = (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash.ToLowerInvariant()
    }
  }
```

Use those exact values in upload-session requests. Publisher URLs can change;
never replace a committed source merely because the filename is similar.

## Original P.A.T.C.H. fixtures

The five files under `pdfs/fixtures/` are original test artifacts generated by
`tools/generate_fixture_pdfs.py`. They intentionally contain fictional asset
details and prominent `TEST ONLY` markings. Regenerate them only when expected
facts and the corresponding test matrix are updated together.

The generator writes final PDFs only to the requested fixture directory. Any QA
rendering must use an external temporary directory such as `$env:TEMP`; do not
place assistant scratch files or rendered page images in this repository.
